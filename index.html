Integração WhatsApp & Atendimento

1. Bot de WhatsApp no n8n (Projeto n8n_evo existente)

Como conectar as mensagens que chegam no WhatsApp ao Ollama da sua própria VPS.

  1. Abra seu n8n existente na VPS: No fluxo que recebe o Webhook da Evolution API.
  2. Adicione um nó "HTTP Request":
    • Method: POST
    • URL: https://lynxhub.lynxems.com.br/v1/chat/completions
    • Headers: Content-Type: application/json e Authorization: Bearer sua_chave
  3. Configure o Body JSON: 
    {
  "model": "qwen2.5-coder:1.5b",
  "messages": [
    {
      "role": "system",
      "content": "Você é o assistente virtual da empresa. Responda em no máximo 2 frases curtas e cordiais."
    },
    {
      "role": "user",
      "content": "={{ $json.body.data.message.conversation }}"
    }
  ],
  "temperature": 0.7
}
  4. Envie de volta para o WhatsApp: No nó seguinte da Evolution API, pegue o campo {{ $json.choices[0].message.content }} e envie como mensagem de texto.

Backend & APIs

4. Backend (Node.js, Python, PHP, Java, Go)

Conecte usando os SDKs oficiais da OpenAI sem instalar pacotes estranhos.

Como o Ollama na sua VPS segue a especificação da OpenAI, basta mudar apenas 1 parâmetro (baseURL):

// Node.js
import OpenAI from "openai";

const ai = new OpenAI({
  baseURL: "https://lynxhub.lynxems.com.br/v1", // Aponta p/ seu domínio com SSL!
  apiKey: "sua_chave_gerada"
});

const completion = await ai.chat.completions.create({
  model: "qwen2.5-coder:1.5b",
  messages: [{ role: "user", content: "Olá!" }]
});

Conexão por MCP (Model Context Protocol)

O Model Context Protocol (MCP) é o padrão aberto que conecta assistentes como Cursor, Claude Desktop, Antigravity IDE e Windsurf diretamente à sua VPS, permitindo que eles usem a sua IA para programar, analisar e responder perguntas.

Configuração MCP Pronta para Copiar

Stdio JSON-RPC

Cole o bloco abaixo no arquivo de configuração do seu cliente MCP (por exemplo: claude_desktop_config.json ou nas configurações de MCP do Cursor / Antigravity):

claude_desktop_config.json • Configuração MCP 
{
  "mcpServers": {
    "lynx-vps-ai": {
      "command": "python",
      "args": [
        "c:/Users/lynx/Documents/Ai Lynx na VPS Easy Panel/mcp_server.py"
      ]
    }
  }
}

Ferramentas que o Servidor MCP Disponibiliza:

ask_vps_ai Envia prompts e tarefas para qualquer modelo de IA rodando na sua VPS Hostinger (ex: qwen2.5-coder:1.5b, llama3:latest).
list_vps_models Lista em tempo real quais modelos estão baixados e disponíveis na VPS.

Como Testar o MCP Manualmente

Você pode testar se o servidor MCP está respondendo no seu computador rodando o seguinte comando no terminal:

python mcp_server.py

O arquivo mcp_server.py já está criado na raiz da pasta do seu projeto e se comunica diretamente com a sua VPS (85.31.60.68)!

Instruções passo a passo exatas para garantir que seu lynx_ai aceite conexões externas dos seus apps com máxima performance e segurança.

1

Ajustar as Variáveis de Ambiente no Serviço Ollama

No seu EasyPanel em http://85.31.60.68:3000, acesse o projeto lynx_ai → clique no serviço ollama → vá na aba Environment (Ambiente).
